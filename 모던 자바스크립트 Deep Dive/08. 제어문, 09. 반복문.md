## 8.2 조건문
 - if문의 조건식이 불리언 값이 아니면 값으로 평가되어 암묵적 불리언 값으로 강제 변환 되어 코드 블록을 결정함

### switch문
 - case문이 없다면 실행 순서는 default 문으로 이동
 - 폴스루(fall-through)
   - break가 없으면 다음 case로 이어지고 default까지 진행되는데 이걸 폴스루라고 함.
  ```
    switch (undefined) {
      case console.log(1):
      case console.log(2):
    }
  ```

## 8.3 반복문
  - 반목문 대체 가능 다양한 기능
    > 배열 순회 -> forEach
    > 
    > 객체 프로퍼티 열거 -> for ... in
    > 
    > 이터러블 순회 -> for ... of

## 9.1 타입 변환이란?
 - 개발자가 의도적으로 값을 변환 하는 것 명시적 타입 변환 or 타입 캐스팅
 - 개발자가 의도적 X 값을 변환 하는 것 암묵적 타입 변환 or 타입 강제 변환

## 9.4 단축 평가
 - 객체의 프로퍼티를 참조하는 값이 기대하는 변수 값이 객체가 아닌 경우 null or undefiend 경우 타입 에러 발생으로 프로그램이 종료됨.
 - 단축 평가를 사용하면 에러 발생하지 않음
   ```
   var e = null
   var v = e && e.value // null
   ```
### 옵셔널 체이닝
   ```
   var e = null
   var v = e?.value 
   console.log(undefined)
   ```

### null 병합 연산자
  ```
  var foo = '' || 'default value'
  console.log(foo) // default value

  var foo = '' ?? 'default value'
  console.log(foo) // ''

  var foo = 0 ?? 'default value'
  console.log(foo) // 0
  ```
