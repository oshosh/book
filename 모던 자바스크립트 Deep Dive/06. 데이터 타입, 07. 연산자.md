## 6.1 숫자 타입
 - JS는 64비트 부동소수점 형식으로 실수로 처리하며, 정수만 표현하기 위한 데이터 타입이 존재 하지 않음.
 - `Infinity`, `-Infinity`, `NaN` 의 특별한 값도 표현 할 수 있다.

## 6.2 문자열 타입
 - 문자열은 0개이상의 16비트 유니코드 문자(UTF-16)의 집합으로 표현

## 6.3 템플릿 리터럴
### 멀티라인 문자열
 - 일반 문자열은 이스케이프 시퀀스를 사용해야함
 - 템플릿 리터럴은 이스케이프 시퀀스 사용하지 않아도 줄바꿈이 허용
```
var str = 'Hello
world.'; // SyntaxError: Invalid or unexpected token

var str = `Hello
world.`; // Hello\nworld.
```

### 표현식 삽입
 - 템플릿 리터럴 사용시 가독성 및 문자열 조합이 쉬움
```
var first = 'se-hyun'
var last = 'oh'

console.log(first + ' ' + last) // se-hyun oh

var first = 'se-hyun'
var last = 'oh'

console.log(`${first} ${last}`) 
```

### 6.5, 6.6 undefined, null 타입
 - `undefined`는 초기화 되지 않은 변수이기 때문에 임의 할당은 혼란을 줄 수 있다.
 - 값이 없다는 것을 명시 하고 싶을 경우 `null`을 할당한다.


### 6.7 심벌 타입
 - 변경 불가능한 원시 타입 값 심벌 값은 다른 값과 중복되지 않는 유일한 값이다.

### 6.9 데이터 타입이 필요한 이유
 - 값을 저장할때 메모리 공간 크기 결정
 - 값 참조 시 한번에 읽어 들어야 할 메모리 크기 결정
 - 메모리에서 읽힌 2진수 해석 결정

### 6.10 동적 타이핑
 - 자바스크립트의 변수는 선언이 아닌 할당에 의해 타입이 결정 됨 = 타입 추론
 - 그리고 언제든지 재할당 시 동적 변경 됨
