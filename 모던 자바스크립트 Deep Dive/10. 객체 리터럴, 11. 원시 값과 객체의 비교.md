## 10.1 객체란
 - 객체 타입 값, 즉 객체는 변경 가능한 값
 - 모든 값은 프로퍼티 값이 될 수 있다.
 - 식별자 네이밍 규칙을 따르지 않는 이름에는 반드시 따옴표를 사용해야함
   ```
   var person = {
     name: 'Lee', // 프로퍼티
     age: 20 // [프로터티 키] : 프로퍼티 값 => 프로퍼티
   }

   var counter = {
     num: 0,
     increase: function () {  // 메서드
       this.num++;
     }
   }

   var person = {
     firstName: 'Sehyun',
     'last-name': 'Oh' // last-name -> 식별자 네이밍 규칙 안지키면 SyntaxError: Unexpected token
   }

   console.log(person.last-name) // NaN, name은 windows 함수를 가르키고 last는 undefiend라 요상한 에러가 발생함...
   ```

## 11.1 원시 값
  - 원시 타입의 값, 변경 불가능한 값 (값에 의한 전달)
    ```
    // str 문자열은 Hello가 저장된 메모리 공간의 첫번째 메모리 셀 주소를 가리킴
    var str = 'Hello'
    // 'world' 메모리에 생성하고 식별자 str를 가리킴
    str = 'world'
    ```

### 유사 배열 객체
 - 마치 배열처럼 인덱로 프로퍼티 값에 접근 할 수 있고 length 프로퍼티를 갖는 객체
 - 아래 예제와 같은 문자열은 변경 불가능 한 원시 타입 값이기 때문에 값 변경이 불가하고 데이터 신뢰성을 보장한다.
   ```
   var str = 'string'
   console.log(str[0]) // s

   console.log(str.length) // 6

   str[0] = 'S'
   console.log(str) // string
   ```

### 값에 의한 전달
 - `copy === score`가 같아보여도 다른 메모리 공간에 저장된 별개의 값이기 때문에 해당 아래 결과 또한 변경되어도 원시 타입 값 변경이 되지 않는다.
```
var score = 80;
var copy = score

console.log(score) // 80
console.log(copy)  // 80
console.log(copy === score)  // true

score = 100

console.log(score) // 100
console.log(copy)  // 80
```

## 11.2 객체
 - 프로퍼티 개수가 정해져 있지 않음
 - 동적 추가 삭제 가능
 - 프로퍼티의 값도 제약이 없음

### 변경 가능한 값
 - 객체 타입 값, 즉, 변경 가능한 값이다.
   ```
   var person = {
    name: 'Oh'
   }
   
   // person 변수에 저장되어 있는 참조 값으로 실체 객체에 접근
   console.log(person) // {name: "Oh"}
   ```
<img width="351" height="289" alt="image" src="https://github.com/user-attachments/assets/889638e1-5b32-436c-b331-8fdcb8aa58ee" />

 - 원시 값은 변경 불가능 값이나 객체는 변경 가능한 값이므로 메모리에 저장된 객체를 직접 수정 할 수 있다.
 - 객체는 할당한 변수에 재할당을 하지 않았으므로 객체를 할당한 변수의 참조 값은 변경되지 않음.
 - 객체 변경 시 원시 값 처럼 복사해서 새로 생성하면 명확하고 신뢰성이 확보되겠지만 생성 비용과 메모리 효율적 소비가 어렵고 성능이 나빠진다.

### 얕은 복사와 깊은 복사
```
// 얕은 복사
const o = {x: { y: 1 }}
const c1 = { ...o }

console.log(c1 === o) // false -> 얕은 복사에 의해 실제로 {y:1} 은 복사되지 않음 즉, 서로 다른 객체
console.log(o.x === c1.x) // true -> 얕은 복사로 안에 참조하는 객체는 같은 주소를 바라봄
console.log(o.x.y === c1.x.y) // true -> 객체의 값의 접근이기 때문에 같다.

// 깊은 복사
const _ = require('lodash')
const c2 = _.cloneDeep(o)
console.log(c2 === o) // false -> 서로 다른 객체
console.log(c2.x === o.x) // false -> 서로 다른 객체
console.log(c2.x.y === o.x.y) // true -> 객체의 값의 접근이기 때문에 같다.
```
