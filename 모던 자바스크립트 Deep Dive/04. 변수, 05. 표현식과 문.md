## 4.3 변수 선언
 - 변수 사용시, 반드시 선언 필요 var, let, const 키워드 사용 한다.
### ES5 vs ES6 
 - `var`는 `let`, `const`와 같은 블록 레벨 스코프를 지원하지 않고 함수 레벨 스코프 지원을 한다.
### 자바스크립트 엔진 변수 선언
 - 선언 후 아직 변수에 값을 할당 하지 않았지만 `undefined`라는 값을 암묵저으로 할당되어 초기화 (선언, 초기화)
 - 선언 하지 않은 식별자 접근 시 `ReferenceError` (참조 에러) 발생
```
var score; // 선언, 초기화

average // ReferenceError
```

### 변수 이름은 어디에 등록?
 - 자바스크립트 엔진이 소스코드를 평가하고 실행하기 위한 환경 제공, 코드 실행 결과 관리 영역인 `실행 컨텍스트`에 등록된다.

## 4.4 변수 선언의 실행 시점과 변수 호이스팅 
 - 변수의 선언은 런타임 전에 이미 실행되면서 이처럼 코드의 선두로 올라간것 처럼 동작하는 특징을 호이스팅이라고 한다.
```
console.log(score) // undefined
var score // 변수 선언
```

## 4.5 값의 할당
 - 값의 할당은 소스코드가 순차적으로 실행되는 런타임에서 실행된다.
 - 엄밀히 말하면 80으로 할당 한 값 또한 재할당이라고 할 수 있고, 값을 재할당 할 수 없는 변수는 상수라고 한다.
 - 메모리에서 자동 해제되는 가비지 콜렉터가 있지만 언제 해제 되는지 예측 불가하며 메모리 누수를 방지한다.
```
var score
score = 80;
```
