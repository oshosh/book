## 13.1 스코프란?
  - 유효범위에 따라 식별자를 참조 할 수 있는 범위
  - js에서는 대표적으로 `var` 함수 스코프, `let`, `const` 블록스코프가 있고 선언에 따라 다르게 동작함
    ```
    var x = 'global';

    function foo() {
      var x = 'local'
      console.log(x) // local
    }

    foo()
    console.log(x) // 'global'
    ```

### 코드의 문맥과 환경
  - Javascript 가 실행되기 위해 필요한 환경을 제공하는 객체를 `실행 컨텍스트`라고 하고 그 환경 속에 코드가 어디에서 실행되며 주변에 어떤 코드가 있는지를 렉시컬 환경이라고 한다.
  - 렉시컬 스코프는 함수를 어디서 정의했지는지에 따라 상위 스코프가 결정된다.

### var 키워드로 선언한 변수의 중복 선언
  ```
  function foo() {
      var x = 1
      // var의 경우 같은 스코프 내 중복 선언 허용
      var x = 2
      console.log(x) // 2
    }

  function bar() {
    let x = 1 // 블록 스코프는 불가능하다.
    let x = 2 // SyntaxError: Identifier 'x' has already been declared
  }
  ```

## 13.3 스코프 체인
  - 모든 지역 스코프의 최상위 스코프는 전역 스코프이다
  - 계층적으로 연결된 것을 스코프 체인이라고 함.
  - 상위 스코프에서 유효한 변수는 하위에서 자유롭게 참조가 가능하지만 하위 스코프에서 유효한 변수를 상위 스코프에서 참조할 수 없다.

## 13.4 함수 레벨 스코프
  - 함수 레벨 스코프와 블록 레벨 스코프의 차이
  ```
  var i = 10
  // i는 전역 변수로 호이스팅 됨
  for (var i = 0; i<5; i++){
    console.log(i) // 0 1 2 3 4
  }

  console.log(i) // 5

  let i = 10
  for ( let i = 0; i<5; i++){
    console.log(i) // 0 1 2 3 4
  }

  console.log(i) // 10
  ```
