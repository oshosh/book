# 함수형 프로그래밍은 무엇인가요?
  - 함수형 프로그래밍이란?
    1. **수학 함수**를 사용하고 **부수 효과(side effect)**를 피하는 것이 특징인 프로그래밍 패러다임
    2. **부수 효과** 없이 **순수 함수(pure function)**만 사용하는 프로그래밍 스타일

  - 부수 효과
    - 함수가 리턴값 이외 하는 모든일
    - 부를 때마다 발생하기에 문제가 될 수 있음
    - 최대한 함수형 프로그래밍에서는 사용하지 않아야함

  - 순수 함수
    - 부수 효과가 없는 함수로서 인자에 의존하며 같은 인자는 항상 같은 결과로 돌려줌
    - 순수 함수 = 수학함수

# 실용적인 측면에서 함수형 프로그래밍 정의의 문제점
  - 문제 1. 부수 효과는 필요하다.
    - 필요에 의해서 사용은 필수 불가결하다.
  - 문제 2. 함수형 프로그래밍은 부수 효과를 잘 다룰 수 있다.
    - 잘 다룰 수 있는 기술들이 많다.
  - 문제 3. 함수형 프로그래밍은 실용적
    - 잘 만들어진 소프트웨어가 많다.

# 액션과 계산, 데이터 구분하기
  - 액션, 계산, 데이터를 구분하여 기술과 개념으로 함수형 프로그래밍을 바라보자.
    ```
    { "firstname": "Ha", "lastname": "Hyun joon" }
    sendEmail(to, from, subject, body) -> 액션
    sum(numbers)
    saveUserDB(user) -> 액션
    string_length(str)
    getCurrentTime() -> 액션
    [1,10,2,45,3,98]
    ```
# 함수형 프로그래머는 부를 때 조심해야 하는 코드를 구분합니다.
  - 선 하나 긋고 호출 횟수, 호출하는 시점이 중요한 함수는 올려보자.
    ```
    <!-- 액션은 부르는 시점에 의존 -->
    sendEmail(to, from, subject, body)
    saveUserDB(user)
    getCurrentTime()
    ---------------------------------------------------
    <!-- 부르는 시점이나 횟수가 중요하지 않은 코드 -->
    { "firstname": "Ha", "lastname": "Hyun joon" }
    sum(numbers)
    string_length(str)
    [1,10,2,45,3,98]
    ```

# 함수형 프로그래머는 실행하는 코드와 그렇지 않은 코드를 구분합니다.
  - 계산과 데이터는 둘다 부르는 시점이나 횟수가 중요하진 않다.
  - 계산은 실행 가능 데이터는 그렇지 않음
  - 데이터는 정적이고 계산은 동적이다.
    ```
    <!-- 액션은 부르는 시점에 의존 -->
    sendEmail(to, from, subject, body)
    saveUserDB(user)
    getCurrentTime()
    ---------------------------------------------------
    <!-- 데이터는 실행전까지 어떻게 동작할지 알 수 없음-->
    sum(numbers)
    string_length(str)
    ---------------------------------------------------
    <!-- 데이터는 이벤트에 대한 사실을 기록 정적이다. -->
    { "firstname": "Ha", "lastname": "Hyun joon" }
    [1,10,2,45,3,98]
    ```
