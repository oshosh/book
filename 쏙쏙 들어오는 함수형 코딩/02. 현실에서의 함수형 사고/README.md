# 파트1: 액션과 계산, 데이터
  1. 액션
    - 호출 횟수와 시점에 의존하는 것 (ex) 반죽펴기, 피자 **자주 바뀌는 것** 배달, 재료 주문
  2. 계산
    - 어떤 것을 결정하거나 계획하며 실행해도 다른 곳에 영향을 주지 않음 (ex) 조리법에 나온 것을 두 배로 만들기, 쇼핑 목록 결정
  3. 데이터
    - 변경 불가능한 데이터 (ex) 고객 주문, 영수증, 조리법

# 변경 가능성에 따라 코드 나누기

## 계층화 설계 맛보기
  - 위쪽으로 갈수록 자주 변경
  - 비즈니스 규칙, 도메인 규칙, 기술 스택 계층으로 나눔

| 변경 빈도           | 레이어           | 구성요소        | 설명                                      |
| --------------- | ------------- | ----------- | --------------------------------------- |
| **자주 바뀌는 것**    | **피자 주방 레이어** | 이번 주 메뉴     | • 이번 주 특별 메뉴를 위한 조리법                    |
|                 |               | 피자 만들기      | • 조리법 순서                                |
| **자주 바뀌지 않는 것** |               | 자바스크립트      | • 객체<br>• 배열                            |
| **자주 바뀌는 것**    | **창고 레이어**    | 이번 주 사야 할 것 | • 재료를 어디서 구입할지 결정                       |
|                 |               | 재료 목록       | • 재료 목록에 대한 동작                          |
|**자주 바뀌지 않는 것**                 |               | 자바스크립트      | • 객체<br>• 숫자                            |

| **자주 바뀌지 않는 것**  |               | 기술 스택       | 최소한 성과가 비즈니스, 도메인 및 기술 문제를 명확하게 분리하도록 함 |

# 파트2: 일급 추상
  - 타임라인 다이어그램
    - 액션이 시간 순서에 따라 어떻게 실행 되는지 확인 할 수 있고 실행 시점에 의존하기 때문에 실행 순서가 중요
  | 실행 순서 | 단계       | 설명                |
| ----- | -------- | ----------------- |
| 1     | 주문 접수    | 여기서 시작            |
| 2     | 반죽 만들기   | 준비하고 다음 단계로 이동    |
| 3     | 반죽 펴기    | 사용하고 다음 단계로 이동    |
| 4     | 소스 만들기   | 준비하고 다음 단계로 이동    |
| 5     | 소스 뿌리기   | 사용하고 다음 단계로 이동    |
| 6     | 치즈 긁기    | 준비하고 다음 단계로 이동    |
| 7     | 치즈 뿌리기   | 사용하고 다음 단계로 이동    |
| 8     | 오븐에 넣기   | 사용하고 다음 단계로 이동    |
| 9     | 10분 기다리기 | 사용하고 다음 단계로 이동    |
| 10    | 서빙       | 여기까지 오면 피자가 완성됩니다 |


# 분산 시스템을 타임라인으로 시각화하기
  - 작업을 분산 시켜 각기 다른 작업으로 분산 시켜 함께 일함
  - 독립된 액션의 실행 순서는 어떤게 먼저 끝날지 순서가 섞여 엉망이 될 가능성이 높다
  - 타임라인을 서로 맞추지 않은 분산 시스템은 예측 불가능한 순서로 실행된다.

  | 로봇 A 타임라인 | 로봇 B 타임라인 | 로봇 C 타임라인 |
| --------- | --------- | --------- |
| 주문 접수     | 주문 접수     | 주문 접수     |
| 반죽 만들기    | 치즈 갈기     | 소스 만들기    |
| 반죽 펴기     | 치즈 뿌리기    | 반죽 펴기     |
| 소스 뿌리기    | 오븐에 넣기    | 소스 만들기    |
| 치즈 긁기     | 10분 기다리기  | 소스 뿌리기    |
| 치즈 뿌리기    | 서빙        | 치즈 뿌리기    |
| 오븐에 넣기    | -         | 오븐에 넣기    |
| 10분 기다리기  | -         | 10분 기다리기  |
| 서빙        | -         | 서빙        |
